# Milestone 5: Manufacturer fitting and controlled live launch

Status: **software implemented and CI verified; hosted release, physical approval and live launch pending**. The customer has no live Shopify store yet and no manufacturer-approved drawings, tolerances, or measured diamond files. The Aerow development pilot remains a visual pilot. No manufacturer fitting release has been fabricated or published, and no live checkout has been enabled.

## Implemented

1. **Evidence and approval records.** The Shopify Admin fitting page holds a revisioned draft for setting/head assemblies, exact Shopify diamond variants, certificate-backed millimetre measurements, and manufacturer approvals for specific metal and size combinations. Evidence files stay in private controlled storage; the app stores references and SHA-256 digests. Publication checks the active catalog, model versions, variant mappings, coverage and duplicate approvals. Published releases are immutable; suspension removes the active release without rewriting saved designs.
2. **Customer and quote gates.** When `REQUIRE_FITTING_APPROVAL=true`, the storefront shows only approved stone and size combinations. An exact server-side fit match is required before a quote. The quote transaction rechecks the active fitting release, stores the release, approval and measurement evidence in the immutable design, and signs them into the cart ticket. The 3D model remains representative even for a physically approved combination.
3. **Checkout enforcement.** The Shopify validation function requires the currently active fitting release and the signed approval on every managed ring component. A suspended or replaced release invalidates prior tickets. Catalog guard expansion and fitting release changes share a per-shop lock, so concurrent Admin actions cannot overwrite each other's guard configuration. The fitting state and suspension audit commit together; quotes also compare the active release against the installed guard. Unrelated products can still check out if the guard metafield is missing or malformed; marked ring lines fail closed. Optional standalone variant exemptions require an exact, reviewed ID list and do not exempt marked configured-ring lines.
4. **Manufacturing decisions.** A separate decision record is tied to the current Shopify order audit and cart group. An `approved` decision requires settled payment, no cancellation or refund, verified components, and a saved design whose fitting release is still active. A fresh order audit or fit suspension makes an older decision stale. Hold and reject remain available for exceptions. This action does not fulfill, refund, cancel, or reserve stock.
5. **Recovery.** Encrypted backup format v2 includes fitting state, releases and manufacturing decisions. The reader still accepts v1 Milestone 4 archives. Session tokens remain excluded. A restore requires an isolated, empty local schema and verifies table hashes.

## Safe activation sequence for a future live store

1. Establish the exact live `myshopify.com` domain, confirm its actual Shopify Plus plan and checkout-validation capability, and install the app with scoped access. Keep `ENABLE_PURCHASES=false` and `ENABLE_LIVE_PURCHASES=false` while staging. Map live products, variants, inventory location, theme extension and app proxy independently of development IDs.
2. Obtain approved head drawings, tolerances, measured stone files and manufacturer sign-offs. Retain the originals privately, record SHA-256 digests and references, enter each exact head/stone/metal/size approval in **Fitting approvals**, and validate the draft. Do not infer dimensions from carat weight or the visual GLB.
3. Review whether mapped diamonds or engraving services may be purchased alone. If they may, specify only their exact standalone variant IDs in `LIVE_GUARD_EXEMPT_VARIANT_IDS` and enable `LIVE_ALLOW_STANDALONE_COMPONENTS`; keep setting products managed. Install and verify the checkout guard with `blockOnFailure=true` and confirm the registry against the live catalog.
4. Set `PILOT_ALLOWED_SHOP` and `LIVE_ALLOWED_SHOP` to the exact live domain, `REQUIRE_FITTING_APPROVAL=true`, then publish the reviewed fitting release. Check that the guard reports the same release before enabling `ENABLE_PURCHASES=true` and `ENABLE_LIVE_PURCHASES=true`. The backend also checks Shopify's actual `shopifyPlus` plan field.
5. Test approved and disallowed combinations, an expired or tampered cart ticket, unrelated cart lines, and a complete live-store test checkout using a safe test method. Confirm the order projection, preview, fit evidence and manufacturing gate. Inspect desktop and a physical iPhone; record model, OS, browser and performance. Obtain a physical Android device before claiming Android acceptance. Only then expose the live theme page to customers.
